# 会计成本中心电脑端报表布局设计

## 背景与目标

会计成本中心新增工资记录、经营费用、采购对账和月度汇总的导出功能后，操作按钮仅使用基础横排样式，缺少清晰的容器、层级和对齐关系。PDF 提示文字还会挤到按钮之间；顶部五个入口在电脑端容易换行，导致页面松散且不易扫读。

本次改造以现有“项目成本”的操作卡片为视觉基准，统一会计成本中心的电脑端布局。只调整界面结构、间距、对齐和状态样式，不改变筛选、数据、权限、导出、打印或业务计算逻辑。

## 已确认范围

- 顶部“工资记录、项目成本、经营费用、采购对账、月度汇总”入口改为电脑端单行五栏标签。
- 工资记录、经营费用、采购对账、月度汇总使用统一报表操作卡片。
- 项目成本保留现有操作卡片和功能，作为共享样式基准。
- 现有筛选区、录入表单、统计卡片、表格内容及其顺序不变，只修正与操作卡片之间的间距和对齐。
- 保留现有黑金主题；Excel、PDF 和打印内容继续使用现有白纸报表样式。

## 顶部标签栏

- 桌面宽度下将当前账号可见的入口等分为一行，管理员最多显示五个；权限隐藏栏目后，剩余入口自动重新等分，不留下空位，也不允许月度汇总单独掉到第二行。
- 整体使用统一外框和深色背景，入口之间保持清楚但不过度分割。
- 当前入口使用金色边框、金色文字和轻量金色底色；未选中入口保持低对比文字和透明背景。
- 标签高度收紧到适合电脑鼠标操作的尺寸，避免当前大面积空白。
- 较窄窗口下保持单行并允许横向滚动，不压缩文字、不折行。
- 继续使用现有按钮语义和选中状态，不改变栏目切换逻辑与权限控制。

## 统一报表操作卡片

四个新增栏目在内容顶部使用与项目成本一致的横向卡片：

- 左侧为报表名称和一行范围说明。
- 右侧为“导出 Excel”“导出 PDF”“打印”三个操作。
- PDF 提示固定在 PDF 按钮正下方，作为该按钮的一部分，不影响其他按钮垂直对齐。
- 卡片使用现有主题变量：深色表面、细金色边框、顶部金色强调线、圆角和一致内边距。
- 按钮使用项目成本相同的高度、字重、边框、圆角、悬停和禁用表现。
- 正常状态下按钮横向排列；空间不足时只允许按钮组内部合理换行，不让标题与按钮互相挤压。

各栏目文案：

- 工资记录：标题“工资记录报表”，说明当前月份和员工筛选范围。
- 经营费用：标题“经营费用明细”，说明当前月份、费用类型和项目范围。
- 采购对账：标题“采购对账报表”，说明当前月份、项目、来源和付款状态范围。
- 月度汇总：标题“月度成本汇总”，说明当前统计月份与可见成本范围。

## 页面内容顺序

- 工资记录、经营费用、月度汇总：操作卡片在最上方，现有筛选或录入内容紧随其后。
- 采购对账：操作卡片在最上方，筛选面板移到卡片下方，随后保持现有状态提示、统计卡片和明细表。
- 页面主要区块之间使用一致的纵向间距，避免标题、按钮、筛选区和统计卡片粘连。

## 状态与交互

- 数据加载、错误、权限不可见、报表不可用和导出处理中，继续使用现有禁用判定和提示内容。
- 禁用按钮保持清晰可辨，但降低对比度且显示不可操作光标。
- 导出 Excel、导出 PDF 和打印的处理流程、快照保护、错误提示和打印弹层挂载方式不变。
- 不新增按钮，不改变任何按钮文字或业务权限。

## 实现边界

- 抽取或扩展共享的报表操作卡片组件，使四个栏目使用同一结构，避免复制四套布局。
- 共享项目成本的主题尺寸和颜色规则；不把项目成本的新增费用、拆分项目功能带到其他栏目。
- 为采购对账调整组件内的视觉顺序，但不改变状态计算、筛选变量或报表模型。
- 样式只作用于会计成本中心，避免影响其他模块的通用按钮、表单和标题。

## 验收与验证

- 桌面宽度下所有可见入口保持单行、等宽、选中态清楚；管理员五个入口完整显示。
- 四个新增栏目均显示完整报表操作卡片，标题在左、三个按钮在右。
- PDF 提示只位于 PDF 按钮下方，按钮整体对齐。
- 切换栏目、修改筛选、导出 Excel、导出 PDF 和打印的既有行为不变。
- 加载、错误、权限、空数据和处理中状态继续按原规则阻止或允许输出。
- 添加真实渲染测试覆盖四个栏目与顶部标签栏；运行相关测试、完整测试和生产构建。
- 在电脑端浏览器逐栏检查页面视觉布局和主要按钮交互，确认无横向溢出或不必要换行。

## 非目标

- 不重做会计中心颜色体系。
- 不修改导出的 Excel、PDF 或打印版式。
- 不调整工资、费用、采购或月度成本的统计口径。
- 不新增筛选条件、历史范围或“全部记录”功能。
- 不改造手机端为独立布局；窄屏仅保证标签可滚动和内容不破坏。
