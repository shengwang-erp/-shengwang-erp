# 老板驾驶舱项目经营明细对比度设计

## 目标

老板驾驶舱的“项目经营明细”在黑色面板上使用明确的高对比度文字层级，避免正文或项目名称被浏览器及共享表格样式覆盖成深色或蓝色。

## 已确认视觉规则

- 表格普通正文和金额使用 `--erp-text-primary` 米白色。
- 表头和项目编号使用 `--erp-text-secondary` 浅灰色。
- 项目名称使用 `--erp-text-primary` 米白色。
- 预计利润使用 `--erp-accent-gold` 金色；现有异常、待核算和亏损语义颜色保持不变。
- 修改只作用于 `.executive-project-table`，不改变其他模块的共享表格样式。

## 验收

- CSS 契约测试锁定上述颜色映射。
- 老板驾驶舱渲染测试、完整测试和生产构建通过。
- 线上页面在桌面视口中项目名称、编号、正文金额和预计利润均可清晰阅读。
