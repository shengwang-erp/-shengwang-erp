# 侧栏金属 SW 圆标设计

## 目标

把桌面端管理侧栏顶部现有的纯文字圆形 `SW` 标志，替换为适合 44px 小尺寸显示的金属质感品牌徽记。视觉方向以用户提供的黑铜底、银白立体 SW 参考图为准，同时避免缩小时出现文字拥挤或方形图片边框。

## 范围

- 仅调整桌面端侧栏顶部 `.desktop-admin-brand-mark`。
- 登录页、认证状态页、PWA 图标和浏览器图标不在本次范围内。
- 用户确认预览前，不替换现有侧栏标志。

## 图像规格

- 输出：1024 × 1024 PNG 母版，透明背景。
- 外形：完整圆形徽章，圆外像素必须透明，不得出现方形底框或四角残影。
- 底材：接近黑色的深棕黑铜，具有克制的拉丝或抛光金属质感。
- 外圈：细窄立体金属包边，暖金或古铜色，边缘清晰。
- 主体：只保留银白色立体 `SW` 与环绕椭圆线条；高光、倒角和阴影在 44px 下仍可辨认。
- 禁止内容：不出现“生旺株式会社”、`ERP` 或任何其他文字，不出现水印，不出现额外装饰符号。
- 构图：徽记居中，四周留有均匀安全边距，不使用延伸到圆形外部的投影。

## 生成与预览流程

1. 使用用户提供的金属 SW 图片作为质感和结构参考，生成新的侧栏专用徽记，不直接裁剪原图。
2. 首版只作为预览展示给用户，不接入应用。
3. 用户确认首版后，将最终透明 PNG 保存为 `public/sw-sidebar-mark.png`。
4. 把 `DesktopAdminShell` 中的文字 `SW` 节点改为带替代文本的图片，并调整样式以适配 44px 圆形槽位。

## 验收标准

- 44px 实际显示时，`SW` 和椭圆环仍清楚可辨。
- 标志外轮廓为圆形，看不到方形图片边界、底色或透明毛边。
- 金属高光与黑金 ERP 侧栏协调，不显得过亮或廉价。
- 图标不挤压“生旺株式会社 / ERP 管理数据中心”两行品牌文字。
- 侧栏在桌面端原有布局和响应式断点下不发生位移。
