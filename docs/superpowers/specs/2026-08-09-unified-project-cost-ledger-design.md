# 统一项目成本明细账设计

日期：2026-08-09  
目标分支：`codex/warehouse-forward-port`

## 目标

把 ERP 内所有已经绑定工程项目的费用汇集到会计成本中心，形成可追溯、可调整、可拆分、可打印、可导出的一套项目成本明细账。原始业务记录保持不变；会计修改只形成独立调整值，并自动记录完整审计信息。

## 已确认规则

- 费用一旦绑定有效项目就立即计入，不依赖付款、到货或发票状态。
- 已取消、已删除的业务记录不统计。
- 会计调整立即生效，不需要审批。
- 调整不回写采购、仓库、人工、车辆、工具等原始业务记录。
- 一笔费用可以按金额或比例拆分给多个项目，拆分总额必须严格等于该费用的当前有效金额。
- 会计可以手工新增正数或负数项目费用，用于补录、退款、折扣、冲销和更正。
- 打印内容自动显示调整痕迹，不依赖打印后手写。
- 浏览器打印、PDF 和 Excel 三种输出都必须提供。

## 当前情况

仓库与项目成本已经部分连接：仓库负责人确认项目出库后，系统会按冻结的实际批次成本生成仓库材料成本，并通过来源键防止同一采购材料和仓库出库重复计算。现有会计成本域还能读取采购、人工、车辆和经营费用的部分汇总。

当前不足是这些来源只形成分散汇总或卡片记录，没有一张统一的逐笔项目费用明细表；仓库自动成本不可在会计页面调整；不存在统一的会计覆盖层、跨项目拆分、追加式审计记录以及项目成本专用打印与导出结构。

## 推荐架构

采用“不可变来源事实 + 会计调整覆盖层 + 项目分摊层 + 统一读取模型”。

### 1. 来源事实

每个费用模块通过一个固定适配器转换为统一来源事实：

- 采购：直接绑定项目且没有被仓库成本替代的采购总成本；
- 仓库：已确认项目出库、零散工单领料及其仓库冲销；
- 人工：正式项目人工分摊；
- 车辆：燃油、车辆费用、维修或事故费用中绑定项目的金额；
- 工具：维修、赔偿、责任费用中绑定项目的金额；
- 经营费用：启用项目分摊并绑定项目的费用；
- 现有手工项目成本；
- 以后新增的 ERP 费用模块，只要实现相同适配器即可进入明细账。

统一来源事实至少包含：稳定来源键、来源模块、来源单据类型、业务单号、项目、成本类别、业务日期、说明、原始金额、经办人和来源状态。来源键必须稳定且唯一，用于防止重复统计。

### 2. 会计调整覆盖层

会计调整采用追加式记录，不能覆盖或删除旧审计记录。每一次调整保存：

- 调整记录键；
- 来源事实键；
- 调整前金额；
- 调整值；
- 调整后金额；
- 修改原因；
- 修改人身份及显示名称；
- 服务器修改时间；
- 调整序号。

当前有效金额取来源事实的原始金额，再按顺序应用有效调整。负数最终金额允许用于退款或冲销，但所有金额必须通过安全定点金额校验。

### 3. 项目拆分层

来源事实默认全部归属原项目。会计可以改为按金额或比例分配给多个有效项目。系统把比例换算为金额后，用最后一行吸收安全舍入差异，并在保存前校验所有分配金额之和等于当前有效金额。

拆分调整同样追加审计记录，保存拆分前后快照、修改人、修改时间和原因。项目删除或失效后，历史拆分仍保留展示，但不能再作为新的拆分目标。

### 4. 手工增减项

手工项目费用是一种没有外部业务来源的会计来源事实。必须填写项目、类别、日期、金额、说明、经办人和原因。正数表示补充成本，负数表示退款、折扣、冲销或更正。其后续修改仍通过会计调整层完成，保留原始手工记录。

## 防重复与统计规则

- 已经形成真实仓库批次并由仓库出库计入成本的采购，不再作为直接采购成本重复计入。
- 仓库退回和冲销沿用仓库来源键并以负数反映。
- 每个来源适配器只接受有效、未取消、未删除并且绑定有效项目的记录。
- 按项目、日期和费用类别统计时，使用拆分后的项目归属和调整后的有效金额。
- 分类小计相加必须等于项目总成本；页面、打印、PDF 和 Excel 必须消费同一个读取模型。

## 数据持久化与权限

新增独立的会计调整与项目拆分持久化记录，不改变原始业务表。数据库写入接口必须：

- 重新验证当前员工为在职、启用且密码状态有效；
- 验证项目成本查看或修改权限；
- 从数据库重新读取来源事实及当前调整版本，禁止客户端伪造原金额；
- 使用版本号或行锁防止两名会计同时覆盖；
- 使用服务器身份和服务器时间生成审计字段；
- 拒绝金额溢出、非法小数、拆分不平、无效项目和空白原因；
- 不允许删除历史审计记录。

查看、修改、打印、PDF 和 Excel 分别复用并扩展现有会计权限。只有具备项目成本修改权限的会计或管理员可以新增手工费用、调整金额及拆分项目。

## 页面设计

项目成本页使用宽松、清晰的财务表格，不使用密集的小字号布局。

### 顶部筛选

- 项目；
- 开始日期与结束日期；
- 费用类别；
- 来源模块；
- 全部、仅已调整、仅未调整；
- 关键词搜索。

### 汇总区

显示项目总成本、当前筛选成本、会计净调整、记录数量，并用独立卡片显示各费用类别小计。

### 明细表

主要列为：日期、费用类别、来源、业务单号、费用说明、原金额、会计调整、最终金额、项目或拆分状态、经办人、调整标记、操作。

表格正文使用可读字号、宽松行距和足够内边距。金额右对齐并加粗，类别之间有清楚的视觉间隔。默认每页 20 条，可选择 50 或 100 条，避免把全部记录堆在一个页面。

展开一行后显示来源详情、项目拆分、调整前后金额、修改原因、修改人和修改时间。自动来源不能直接修改原金额，只能新增会计调整；手工来源也通过调整记录变更。

右上角操作为：新增调整费用、拆分项目、导出 Excel、导出 PDF、打印。

## 打印与导出

### 浏览器打印与 PDF

使用同一份横向 A4 打印样式。打印头自动显示公司名称、项目名称、统计日期区间和打印时间。主表按费用类别分组，显示分类小计和项目总计。

主表保持较大可读字号，超出页面时自动分页并重复表头。调整过的记录显示“已调整”。完整调整历史放在后续审计附页，避免主表过密；附页自动显示原金额、修改后金额、修改原因、修改人和修改时间。

PDF 通过专用打印视图生成，内容与纸质打印一致。

### Excel

工作簿包含三个工作表：

1. `项目成本明细`：当前筛选后的逐笔有效成本；
2. `分类汇总`：费用类别小计和项目总计；
3. `调整记录`：完整自动审计历史和拆分快照。

所有工作表包含明确标题、冻结表头、筛选、合适列宽、金额格式和打印区域。

## 错误处理

- 任一来源暂时不可用时，不把缺失数据当作零；页面明确列出不可用来源并禁止把不完整结果标记为完整报表。
- 保存冲突时提示刷新后重试，不覆盖其他会计的最新修改。
- 导出或打印前固定当前成功筛选快照，未应用的筛选条件不能污染报表标题或数据。
- Excel、PDF 或打印失败时保留当前页面状态并显示可恢复错误。

## 测试与验收

实施采用测试驱动方式，覆盖：

- 每一种费用来源正确进入统一明细账；
- 采购与仓库成本防双计；
- 取消、删除和未绑定项目记录被排除；
- 正负调整、连续多次调整和并发冲突；
- 按金额和比例跨项目拆分及舍入；
- 手工增减项；
- 权限、服务器审计字段和原始记录不变；
- 筛选、分页、分类小计和总计一致；
- 打印、PDF 与 Excel 使用同一数据快照；
- Excel 三工作表内容、打印分页和可读字号；
- 现有仓库、采购、人工、车辆、工具、会计、权限和完整构建回归。

最终浏览器验收至少覆盖首页进入会计成本中心、项目筛选、调整金额、拆分项目、审计展开、Excel 导出、横向 A4 打印预览及 PDF 保存入口。
