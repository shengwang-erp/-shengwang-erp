# 会计成本模块金色文字设计

## 目标

将黑金主题下“会计成本”模块中仍显示为深蓝色、在黑色背景上难以辨认的说明文字统一改为系统现有金色，同时保持金额、边框、状态色和其他业务模块不变。

## 修改范围

- 仅作用于 `.erp-black-gold .accounting-cost-page`。
- 月度汇总卡片的说明文字使用 `var(--erp-accent-gold-soft)`。
- “月度汇总”“待核算成本”等小节标题及其右侧说明使用同一金色。
- 会计模块其他页面中复用上述卡片和小节标题的文字同步生效。

## 明确不修改

- 金额数字继续使用 `var(--erp-text-primary)`，保持白色。
- 卡片背景、顶部强调线和边框颜色不变。
- 成功、警告、错误和信息状态色不变。
- 输入框、按钮、人员管理、工程项目及其他模块不受影响。
- 不修改数据库结构、权限或任何业务数据。

## 实现方式

在 `src/blackGoldTheme.css` 中增加会计页面专属的高优先级选择器，覆盖旧版 `styles.css` 中残留的深蓝色文字规则。避免使用全局通配覆盖，也不修改共享颜色变量。

## 验证标准

1. 先在 `src/blackGoldTheme.test.js` 增加回归断言，并确认修改样式前测试因缺少会计专属金色声明而失败。
2. 添加最小样式后，目标测试与完整测试全部通过。
3. 生产构建成功。
4. 本地桌面页面中，会计卡片说明和小节标题为金色，金额仍为白色。
5. 部署后复核线上 `会计成本 → 月度汇总` 页面。
