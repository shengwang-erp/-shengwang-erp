# iOS 业务界面防白屏诊断设计

## 背景

SW-008（工程部／中工）在电脑浏览器中可以正常使用，在同一台 iPhone 的桌面 ERP 图标中登录后，主界面短暂显示，随后只留下 ERP 自带的浅色网格背景。SW-000 在同一台手机上正常。

现有认证状态页能处理登录与认证服务错误，但登录后的业务界面没有 React 错误边界。业务组件在渲染或生命周期中抛出异常时，React 会移除界面内容，而页面级 CSS 背景仍然存在，因此用户只能看到网格背景，系统也没有提供可用于定位根因的错误信息。

## 目标

1. 登录后的业务界面发生可捕获的运行时异常时，不再只显示网格背景。
2. 显示稳定、可截图和可复制的诊断信息，帮助定位 SW-008 在 iPhone 上的真实错误。
3. 保留“重新加载”和“退出登录”恢复路径。
4. 不显示、记录或上传密码、令牌、姓名、员工编号及业务数据。
5. 不改变现有权限计算、认证状态、数据库结构或业务数据。

## 非目标

- 本阶段不猜测并修改 SW-008 的权限模板。
- 本阶段不新增远程错误日志、数据库表或第三方监控服务。
- 本阶段不保证捕获事件处理器、定时器或独立异步任务中的所有异常；React 错误边界负责捕获渲染、构造和生命周期错误。独立异步错误本身不会导致 React 自动移除整棵业务界面。
- 根因修复将在取得真实诊断信息后单独完成，并继续采用测试驱动方式。

## 方案

### 组件边界

新增一个独立的业务运行时错误边界组件，放置在 `AuthGate` 已认证分支内部、`AuthenticatedApp` 外部。这样：

- 登录页、强制修改密码页和认证错误页继续由 `AuthGate` 管理；
- 登录后的业务组件异常由错误边界捕获；
- 错误页能够使用 `AuthGate` 提供的退出登录回调，安全清除当前会话；
- 业务界面中的任一页面异常不会把认证界面一起破坏。

错误边界只接收恢复回调和子组件，不接收 `currentUser`，从接口层面避免错误页读取或输出用户资料。

### 诊断信息

捕获异常后生成本地诊断对象，内容限定为：

- 固定错误类别，例如 `UI_RUNTIME_ERROR`；
- 当前前端构建版本标识；
- 异常类型和经过长度限制的异常消息；
- 经过长度限制的 React 组件栈；
- 发生时间；
- 浏览器提供的非敏感运行环境摘要（仅操作系统／浏览器类别，不包含完整 User-Agent、设备标识或网络地址）。

诊断对象不得包含组件 props、React state、URL 查询参数、本地存储、会话、令牌、员工资料或业务记录。诊断编号由固定错误类别和构建标识组成，用于确认用户看到的版本；定位细节由用户主动复制或截图提供，不自动上传。

### 错误页面

错误页面沿用现有认证状态页的品牌样式，明确显示“系统页面发生错误”，并提供：

1. `复制诊断信息`：通过 Clipboard API 复制；不可用时显示可手动选择的只读文本。
2. `重新加载`：调用页面重新加载，重新建立干净的 React 状态。
3. `退出登录`：调用认证层退出回调，返回登录页。

错误页不展示原业务页面的残余内容，也不把原始 Error 对象直接插入 DOM。

### 状态恢复

当当前登录身份发生变化时，错误边界需要以认证用户的稳定身份键重新挂载，避免上一个账号的错误状态影响下一个账号。身份键只用于 React 重建边界，不进入诊断文本。

## 数据流

1. `AuthGate` 完成登录并返回已验证的当前用户。
2. 应用以用户稳定身份键挂载业务错误边界。
3. 错误边界正常渲染 `AuthenticatedApp`。
4. 若业务渲染或生命周期抛出异常，错误边界保存安全诊断对象并切换到错误页。
5. 用户复制诊断信息并提供截图，或选择重新加载／退出登录。
6. 取得诊断信息后，根据具体组件和错误消息建立失败测试并修复根因。

## 测试

新增自动化测试覆盖：

- 正常子组件能够透明渲染；
- 子组件抛错时显示错误页，不再返回空 DOM；
- 诊断文本包含类别、构建标识、受限错误消息和组件栈；
- 诊断文本不包含传入测试中的姓名、员工编号、令牌或业务内容；
- `退出登录` 只调用一次认证退出回调；
- `重新加载` 调用受控的 reload 适配器，便于测试；
- Clipboard API 不可用时仍提供只读诊断文本；
- 账号身份键变化后旧错误状态不会泄漏到新账号。

完成后运行目标测试、完整测试套件和生产构建。部署到现有 Vercel 生产项目后，确认正式域名返回成功，再请用户用 iPhone 桌面图标登录 SW-008 复现并提供诊断信息。

## 发布与回退

本次只修改前端，不执行数据库迁移。提交与部署独立可回退；若错误边界本身影响正常登录后的渲染，可以回退该前端提交，不影响线上数据和认证账号。
